# Switch to get-native-data branch to direct access native java data in react native in login form 👋
 

## Get started

1. Switch branch

   ```bash
   git checkout get-native-data
   ```

2. Latest code

   ```bash
   git pull origin get-native-data
   ```
 
3. New clean build

   ```bash
   npx expo run:android
   ```
